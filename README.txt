NEXVIQ DESIGN STUDIO — WEBSITE

FILES
- index.html = website structure
- style.css = design + responsive layout
- script.js = animations, portfolio filters and interactions
- assets/logo/nexviq-logo.png = replace this file with the latest logo if needed
- assets/portfolio/ = replace portfolio images here without changing the HTML filenames

HOW TO USE
1. Keep the folder structure unchanged.
2. Double-click index.html to preview the website in a browser.
3. To replace a portfolio image, put the new image in assets/portfolio and keep the same filename.
4. To change contact details, open index.html and search for the old detail.
5. To publish later, upload the whole NEXVIQ-Website folder to a static hosting service such as Netlify.

NOTE
The current portfolio uses the images supplied in this conversation. Some are screenshot crops, so replacing them with original/high-resolution files later will improve the final presentation.
